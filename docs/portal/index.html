    In TerraWarden, use a group invitation code. An edit code allows adding and editing; a Read-only code allows viewing.

    Joining adds your name to the group's member list. Shared pins, routes and lines use the permissions assigned to this browser.

    Firebase API key Not saved

    Paste the TerraWarden Firebase Web API key. Save it on this browser to use it again after reloading. The key is never added to the website files.
